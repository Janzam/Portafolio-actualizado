# 💫 Portafolio · María Alejandra Zambrano

Ingeniera de Software · **Backend & Full Stack** · Milagro, Ecuador

> Información personal para tener constancia de experiencia práctica.

Portafolio personal interactivo hecho con **HTML, CSS y JavaScript puro** (sin frameworks ni build).

## ✨ Características

- 👋 Bienvenida con texto animado tipo *typing* y fondo de partículas reactivo al mouse
- 🖼️ Foto de perfil con anillo animado, íconos en órbita y efecto 3D
- 💻 Terminal interactiva (`help`, `skills`, `projects`, `sudo hire-me`…)
- 🧰 Tech stack filtrable por categoría y certificaciones (AWS · Anthropic)
- 🚀 Proyectos con filtros y tarjetas con inclinación 3D
- 🎮 Zona de entretenimiento: **Bug Hunter**, **Memory Stack** y frases de devs
- 📫 Formulario de contacto, modo claro/oscuro y un easter egg secreto 🤫

## 🛠️ Ejecutar localmente

Abre `index.html` en el navegador. No necesita instalación.

## 🌐 Despliegue

Desplegado como **Static Site** en [Render](https://render.com) (configuración en `render.yaml`).
